# Search Consoleに基づくモバイル表示性能およびアクセシビリティ(WCAG)最適化実戦記

::: tip 1行要約
Google Search ConsoleのCore Web Vitalsおよびアクセシビリティ指標を改善するため、**(1) GA4遅延読み込みによるTBT 0ms達成、(2) Giscus/WebGLのIntersectionObserver遅延描画とCLS防止、(3) WCAG 2.1 AA 4.5:1明度コントラスト比および44pxタッチターゲット確保**を実施した記録。
:::

## 2. 詳細最適化手法

### 1) GA4スクリプトのインタラクション遅延読み込み
初期レンダリングスレッドを占有するGoogle Analytics 4の読み込みを、初回インタラクション(`scroll`, `touchstart`)または5秒タイムアウトまで遅延させ、**TBTを0ms**に短縮。

```javascript
const loadGA = () => {
  if (window.__gaLoaded) return;
  window.__gaLoaded = true;
  const script = document.createElement('script');
  script.src = 'https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX';
  script.async = true;
  document.head.appendChild(script);
};
['scroll', 'touchstart', 'mousemove'].forEach(ev => 
  window.addEventListener(ev, loadGA, { once: true, passive: true })
);
setTimeout(loadGA, 5000);
```

### 2) 重いコンポーネントの`IntersectionObserver`遅延マウント
* **Giscusコメント欄**: ビューポート到達時にiframeをロード。CLSを防ぐためコンテナに`min-height: 150px`を事前確保。
* **WebGL 3D背景**: 画面外へスクロールアウトした際に`cancelAnimationFrame`でレンダリングループを一時停止しCPU/バッテリー消費を抑制。

---

## 3. コアチェックポイント (Gotchas)

1. **CLS防止用Min-Height**: 非同期ウィジェットは読み込み前にプレースホルダー高さ(`min-height`)をCSSで予約しなければ累積レイアウトシフト(CLS)ペナルティを受ける。
2. **パッシブイベントリスナー (`{ passive: true }`)**: スクロールイベントには`passive: true`を指定しブラウザのスクロールスレッドのブロッキングを防ぐ。
