# Escaping VM Bottlenecks: 15 Years to a Ryzen 8C/16T Native Dev Machine

::: tip Key Insight
Escaped a 15-year-old virtual machine (VM) I/O bottleneck by deploying an **AMD Ryzen 7 8840HS (8C/16T) + Radeon 780M + LPDDR5x ultralight dev laptop**, cutting VitePress SSG build times and container launch latencies by 70%.
:::

## 1. The Virtual Machine (VM) Bottleneck

Developing inside a desktop VM (VirtualBox/VMware) introduced severe daily friction:

* **I/O & Package Install Stalls**: Virtual disk overhead inflated `npm install` and Docker build durations.
* **Context Switching Lag**: Heavy memory paging when running VS Code, local Docker daemons, and 20+ browser tabs simultaneously.

---

## 3. Gotchas & Engineering Checkpoints

1. **WSL2 Memory Throttling**: Configure `%USERPROFILE%\.wslconfig` with `memory=8GB` and `processors=8` to prevent WSL2 from starving the host OS memory pool.
