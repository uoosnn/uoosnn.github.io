# First Blog Post

Hello! I'm starting a tech blog.
This blog is built as a static site (SSG) using **VitePress** and is hosted on GitHub Pages.

## Why I Chose VitePress

1.  **Excellent Performance**: It loads very quickly by minimizing client-side JavaScript.
2.  **High Security**: Since it only serves pure static files, server-side vulnerabilities are fundamentally blocked.
3.  **Clean Documentation-Style Layout**: It provides a 'Docs'-style layout that is familiar to developers, allowing me to focus on the essential content (the writing).

Going forward, I plan to honestly document my development experiences, tech reviews, and problem-solving processes here.
