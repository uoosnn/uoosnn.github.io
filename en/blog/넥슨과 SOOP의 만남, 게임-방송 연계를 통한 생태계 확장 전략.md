# Nexon and SOOP


## News Summary

Nexon and SOOP have signed a partnership. This collaboration aims to expand the user ecosystem by 'connecting' games and broadcasting.

## My Thoughts

Recently, Nexon has been making very aggressive moves to secure more users. According to foreign press reports, there has been internal restructuring within Nexon, and moves have been detected to boldly terminate services for some games with low user counts. This decision is analyzed to be a result of rising development costs and poor performance. The collaboration with SOOP is seen as an extension of this strategy, an attempt to find a new path forward.

## Conclusion and Original Link

Nexon is implementing a strategy to build a new user ecosystem through collaborations with external partners like SOOP, while simultaneously streamlining its underperforming games internally. It will be interesting to see what results the synergy between gaming and broadcasting will bring.
