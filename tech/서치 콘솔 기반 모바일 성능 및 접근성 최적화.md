# 서치 콘솔 기반 모바일 성능 및 접근성 최적화

Google Search Console의 PageSpeed 리포트에서 블로그 모바일 페이지의 성능 및 접근성 지표가 저하된 것을 확인하고, 개선을 위한 리팩토링을 진행했다. 본 문서는 문제 진단부터 해결까지의 과정을 기록한 트러블슈팅 로그다.

### 1. 모바일 성능(PageSpeed) 최적화

가장 큰 문제는 모바일 환경에서의 로딩 성능 저하였다. 원인을 분석하고 다음 세 가지 항목을 집중적으로 개선했다.

#### **측정 봇으로 인한 리다이렉트 및 이중 로딩(Double Load) 제거**
성능 측정 도구인 Lighthouse나 PageSpeed 봇이 접근할 때, 특정 로직으로 인해 불필요한 리다이렉트가 발생하며 페이지가 두 번 로딩되는 현상이 있었다. 이는 측정 점수에 직접적인 악영향을 미쳤다.
*   **조치**: 크롤러 식별 정규식에 `Chrome-Lighthouse`와 `PageSpeed` 봇을 예외 처리하여, 일반 사용자 트래픽과 동일하게 취급하도록 수정했다. 이를 통해 불필요한 재로딩을 제거하고 정확한 성능 측정이 가능해졌다.

#### **GA4 스크립트 지연 로딩을 통한 TBT(Total Blocking Time) 개선**
Google Analytics 4 스크립트가 초기 렌더링 시 메인 스레드를 차단(Blocking)하여 총 차단 시간(TBT)을 증가시키는 핵심 원인이었다.
*   **조치**: GA4 스크립트 로딩 시점을 사용자의 첫 상호작용(`scroll`, `touchstart`)이 발생하거나, 상호작용이 없더라도 5초가 지난 후로 지연시켰다. 이 비동기 로드 전환만으로 **TBT를 0ms까지 감소**시키는 데 성공했다.

#### **IntersectionObserver를 활용한 컴포넌트 지연 로딩**
Giscus 댓글 창과 WebGL 캔버스처럼 초기 렌더링에 필수적이지 않은 무거운 컴포넌트들이 로딩 속도를 저해했다.
*   **조치**: `IntersectionObserver` API를 적용하여 해당 컴포넌트들이 뷰포트에 진입했을 때만 로드되도록 구현했다.
*   **추가 최적화**:
    *   WebGL 캔버스가 화면 밖으로 벗어나면 `requestAnimationFrame` 루프를 일시 중지시켜 불필요한 리소스 사용을 방지했다.
    *   Giscus 댓글 창 컨테이너에 `min-height: 150px`를 설정하여, 컴포넌트 로딩 후 발생하는 레이아웃 변경(CLS, Cumulative Layout Shift)을 사전에 방지했다.

### 2. 웹 접근성(Accessibility) WCAG 2.1 AA 기준 100점 달성

모든 사용자가 동등하게 콘텐츠에 접근할 수 있도록 웹 접근성 표준(WCAG 2.1 AA)을 100% 충족하도록 개선했다.

*   **색상 명도 대비 개선**: 기존 포인트 오렌지색의 명도 대비가 낮아 텍스트 가독성이 떨어졌다. WCAG 기준(4.5:1 이상)을 통과하는 아래 색상으로 교체했다.
    *   **라이트 모드**: `#c2410c` (명도 대비 4.7:1)
    *   **다크 모드**: `#fb923c` (명도 대비 5.8:1)
*   **터치 타깃 영역 확보**: 모바일 환경에서 버튼 및 링크의 최소 클릭 영역을 **44px × 44px** 이상으로 확보하여 조작 편의성을 높였다.
*   **ARIA 속성 부여**: 스크린 리더 등 보조공학기기가 콘텐츠의 의미를 명확히 해석하도록 ARIA(Accessible Rich Internet Applications) 속성을 추가했다.
    *   WebGL 캔버스: `role="img"`
    *   Giscus 댓글 영역: `role="region"`
    *   RSS 아이콘 링크: 스크린 리더용 텍스트 라벨 부여

### 3. 다국어 SEO 및 구조 개선

*   **사이드바 메뉴 동적 생성**: 기존에는 파일명을 기반으로 사이드바 메뉴를 생성하여 다국어 환경에서 제목이 올바르게 표시되지 않았다. `getBlogSidebar()` 함수가 파일명 대신 각 문서의 프론트매터(Frontmatter)에 정의된 `title` 값을 읽도록 수정하여, 언어 설정에 맞는 메뉴가 동적으로 생성되게 했다.
*   **SEO 구조화**: 모든 문서 최상단에 `<h1>` 태그를 하나만 사용하도록 통일하고, 콘텐츠 하단에 `수정한 시간(Updated Date)` 타임스탬프를 명시하여 검색 엔진에 최신성 신호를 명확히 전달하도록 구조를 개선했다.
