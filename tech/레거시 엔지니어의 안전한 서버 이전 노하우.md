## 서론: '레거시 엔지니어'를 아시나요?

스스로를 '레거시 엔지니어'라고 칭합니다. 저의 주된 업무는 2010년대 초반에 출시된 오래된 서버를 사용하는 고객사의 서비스를 다운타임을 최소화하며 최신 환경으로 안전하게 이전하는 것입니다. 낡은 하드웨어, 지원이 끊긴 OS, 구버전의 PHP와 MySQL 등 보이지 않는 위험이 많은 환경 속에서 고객의 비즈니스가 중단 없이 이어지도록 다리를 놓는 역할입니다.

이 글에서는 수많은 이전 작업을 통해 정립한, 다운타임을 최소화하고 안정성을 극대화하는 서버 이전 노하우를 공유하고자 합니다.

## 본론: 안전한 서버 이전을 위한 6단계 프로세스

고객이 가장 우려하는 것은 '혹시 서비스가 멈추거나 데이터가 유실되면 어떡하지?'라는 불안감입니다. 이 불안을 해소하기 위해 체계적이고 투명한 프로세스를 통해 고객이 직접 확인하고 확신을 가질 수 있도록 안내합니다.

### 1단계: 신규 서버 환경 구축

먼저 새로운 서버에 새로운 OS를 설치합니다. 이후 기존 서버에서 사용하던 서비스(APM 등)를 동일 버전 혹은 고객이 원하는 상위 버전으로 마이그레이션 작업을 진행합니다.

### 2단계: 최신 데이터 이전

환경 구축이 완료되면, 금일 새벽에 CDP로 백업된 최신 데이터를 신규 서버로 이전하여 데이터 정합성을 확보합니다.

### 3단계: 고객을 위한 완벽한 테스트 환경 제공

실제 DNS를 변경하기 전에, 고객이 실제 도메인으로 새로운 서버의 동작을 100% 테스트해볼 수 있는 환경을 제공합니다. 이는 로컬 PC의 `hosts` 파일을 수정하여 특정 도메인 요청을 테스트 서버 IP로 보내는 원리를 이용합니다.

**[Windows 기준 테스트 방법 안내]**

1.  **관리자 권한**으로 메모장을 실행합니다.
2.  `파일` -> `열기`를 통해 `C:\Windows\System32\drivers\etc` 경로로 이동합니다.
3.  파일 형식을 `텍스트 파일(*.txt)`에서 `모든 파일(*.*)`로 변경합니다.
4.  `hosts` 파일을 엽니다.
5.  파일의 가장 아래에 아래와 같이 `[테스트 서버 IP] [도메인]` 형식으로 내용을 추가하고 저장합니다.

    ```
    # localhost name resolution is handled within DNS itself.
    #       127.0.0.1       localhost
    #       ::1             localhost
    118.221.120.44 e-kflower.com www.e-kflower.com
    ```

이제 웹 브라우저에서 `e-kflower.com`으로 접속하면, 실제 운영 서버가 아닌 새로운 테스트 서버로 접속됩니다.

> **중요:** 모든 테스트가 완료된 후에는 추가했던 내용을 반드시 삭제하여 `hosts` 파일을 원상 복구해야 합니다.

### 4단계: 고객 테스트 및 최종 확인

고객은 위 방법으로 실제 운영 환경과 동일한 조건에서 웹사이트의 모든 기능이 정상적으로 동작하는지 꼼꼼하게 테스트합니다. 이 과정에서 발견되는 수정 사항은 즉시 반영하며, 고객으로부터 최종 완료 회신을 받을 때까지 대기합니다.

### 5단계: 최종 이전 작업 (IP 맞교체)

고객의 최종 테스트 완료 확인 후, 서비스 이용이 가장 적은 야간 시간을 이용해 최종 데이터 동기화(Sync)를 진행하고 기존 서버와 신규 서버의 IP를 맞교체합니다. 이로써 고객은 사용하던 IP 그대로, 다운타임 거의 없이 업그레이드된 서버를 이용하게 됩니다.

### 6단계: 사후 관리 및 안정화

IP 맞교체 작업이 완료된 후에도 만일의 사태에 대비합니다.
*   **기존 서버:** 새로운 서버에 문제가 없을 경우를 대비해 일주일간 유지 후 회수 처리합니다.
*   **기존 백업 자료:** 용량 확보를 위해 2주간 보관 후 삭제 처리합니다.

## 결론: 신뢰를 이전하는 일

레거시 시스템을 이전하는 것은 단순히 데이터를 옮기는 작업이 아닙니다. 오래된 코드와 설정 속에 숨겨진 비즈니스 로직을 분석하고, 잠재적인 오류를 미리 진단하여 안전하게 현대화하는 '시스템 명의'와 같은 역할입니다.

이처럼 꼼꼼한 절차를 통해 고객의 불안을 신뢰로 바꾸고, 낡고 불안정한 인프라 위에서 운영되던 고객의 소중한 비즈니스를 안전한 최신 환경으로 연착륙시키는 것. 이것이 바로 '레거시 엔지니어'의 자부심입니다.
