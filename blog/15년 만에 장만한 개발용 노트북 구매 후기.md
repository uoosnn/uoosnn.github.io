# 15년 만의 랩톱 전환: VM 병목 탈출과 Ryzen 8C/16T 개발 머신 세팅기

::: tip 핵심 인사이트
15년간 유지해온 데스크톱 가상머신(VM) 환경의 I/O 지연과 컴파일 병목을 탈출하기 위해 **AMD Ryzen 7 8840HS(8C/16T) + Radeon 780M + LPDDR5x 기반 초경량 개발 랩톱**을 세팅하고 로컬 네이티브/WSL2 워크로드를 최적화한 실전 기록.
:::

## 1. 기존 VM(Virtual Machine) 개발 환경의 한계

데스크톱 상의 가상 머신(VirtualBox/VMware) 내에서 블로그 및 풀스택 프로젝트를 진행하면서 심각한 병목에 직면했다:

* **I/O 및 패키지 설치 병목**: `npm install`, Docker 레이어 빌드 시 가상 디스크 드라이버 오버헤드로 인한 대기 시간 폭증.
* **컨텍스트 스위칭 지연**: VS Code, Docker Engine, 브라우저 탭 20개 이상 구동 시 VM 메모리 스왑 발생.

## 3. 실전 개발 환경 전환 체감

1. **VitePress 빌드 시간**: 기존 VM 환경 대비 빌드 속도 70% 이상 단축 (15초 ➔ 3초).
2. **16:10 비율 디스플레이**: 코드 에디터에서 함수 5~6줄을 스크롤 없이 추가로 조망 가능하여 가독성 대폭 향상.
3. **USB-PD 충전 생태계**: 무거운 전용 벽돌 어댑터 없이 65W GaN 충전기 하나로 랩톱과 스마트폰을 통합 관리.

---

## 4. 핵심 체크포인트 (Gotchas)

1. **Windows 11 WSL2 메모리 상한 설정**: WSL2가 기본적으로 호스트 RAM의 50%를 점유하므로, `%USERPROFILE%\.wslconfig`에 `memory=8GB`와 `processors=8`을 명시하여 Windows UI와 리소스를 균형 있게 배분해야 한다.
2. **On-board LPDDR5x 업그레이드 불가**: 온보드 램 특성상 추후 확장이 불가능하므로 구매 시 초기 워크로드(16GB vs 32GB)를 신중히 결정해야 한다.
