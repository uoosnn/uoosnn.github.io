# 15년 만에 장만한 개발용 노트북 구매 후기

거의 15년 동안 데스크톱 환경만을 고수해왔다. 최근 블로그 개발을 위한 환경을 가상 머신(VM) 위의 윈도우에서 진행했는데, 시스템의 전반적인 느린 속도 때문에 더 이상 작업을 이어가기 힘든 수준에 이르렀다. IDE의 반응 속도 저하, 빌드 시간 증가 등 개발 생산성을 심각하게 저해하는 문제에 직면했고, 결국 새로운 개발용 노트북 구매를 결정하게 되었다.

### 기존 개발 환경의 한계

기존 데스크톱에서 VM을 통해 개발 환경을 운영하면서 겪은 주된 병목 현상은 CPU와 I/O 성능 부족이었다. 여러 개의 컨테이너를 동시에 실행하거나, 코드 컴파일과 웹 브라우저의 리소스 사용량이 많아지면 시스템 전체가 느려지는 현상이 빈번했다. 이러한 문제를 해결하기 위해, 멀티태스킹 성능과 빠른 I/O를 최우선으로 고려하여 새 장비를 선택했다.

### 최종 선택: HP 14인치 모델 및 핵심 스펙

오랜 고민 끝에 휴대성과 성능의 균형을 맞춘 모델을 선택했다. 최종적으로 구매한 노트북의 핵심 기술 사양은 다음과 같다.

*   **CPU**: AMD Ryzen™ 7 (8코어 16스레드)
*   **Graphics**: AMD Radeon™ 780M (내장)
*   **RAM**: 16GB LPDDR5x (On-board)
*   **Storage**: 512GB NVMe™ M.2 SSD
*   **Display**: 14인치 WUXGA (1920 x 1200), 16:10 비율, IPS, sRGB 100%
*   **Key Features**: USB-C PD 충전, Wi-Fi 6E

### 스펙이 개발 환경에 미치는 영향 분석

1.  **CPU: Ryzen™ 7 (8C/16T)**
    이전 환경에서 가장 큰 문제였던 멀티태스킹 성능 부족을 완벽히 해소했다. 8코어 16스레드 구성 덕분에 Docker 컨테이너, 로컬 개발 서버, VS Code, 다수의 브라우저 탭을 동시에 실행해도 시스템 지연이 발생하지 않는다. 복잡한 의존성을 가진 프로젝트의 빌드 시간 역시 체감될 정도로 단축되었다.

2.  **GPU: Radeon™ 780M**
    블로그 개발이 주 목적이라 높은 GPU 성능이 필수 요건은 아니었다. 하지만 현존 최상위권의 내장 그래픽인 `Radeon™ 780M`이 탑재되어 있어 시스템 전반의 UI 반응성이 매우 부드럽다. 추후 GPU 가속이 필요한 AI/ML 관련 사이드 프로젝트나 간단한 영상 편집 작업까지도 충분히 감당할 수 있는 잠재력을 확보했다는 점에서 만족스럽다.

3.  **RAM & Storage: 16GB LPDDR5x & NVMe SSD**
    16GB LPDDR5x 메모리는 현대 개발 환경에서 여러 툴을 동시에 운영하기에 충분한 용량이다. 특히 빠른 NVMe SSD와의 조합은 프로젝트 로딩, 패키지 설치 등 I/O 바운드 작업에서 발생하던 대기 시간을 거의 없앴다.

4.  **Display & Portability**
    데스크톱 환경에서는 경험하지 못했던 생산성 향상 요소다. 16:10 비율의 WUXGA 해상도 디스플레이는 세로로 더 많은 코드를 표시해주어 스크롤링을 줄여준다. 또한, 1.38kg의 무게와 USB-C PD 충전 지원은 특정 장소에 얽매이지 않고 개발 작업을 이어갈 수 있는 유연성을 제공한다. 무거운 전용 어댑터 없이도 개발 환경을 유지할 수 있다는 점은 워크플로우에 큰 변화를 가져왔다.

### 결론

느린 VM 환경에서 벗어나 고성능의 네이티브 환경으로 전환한 것은 성공적인 결정이었다. 하드웨어의 제약으로 인해 발생하던 불필요한 시간 낭비를 없애고 온전히 개발에만 집중할 수 있는 기반이 마련되었다. 이 새로운 개발용 노트북이 앞으로의 기술적 성장을 가속화하는 중요한 도구가 될 것이라 기대한다.
