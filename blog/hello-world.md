# 첫 번째 블로그 포스트

안녕하세요! 기술 블로그를 시작합니다.
이 블로그는 **VitePress**를 사용하여 정적 사이트(SSG)로 구축되었으며, GitHub Pages를 통해 호스팅됩니다.

## VitePress를 선택한 이유

1. **뛰어난 성능**: 클라이언트 측 자바스크립트를 최소화하여 매우 빠르게 로드됩니다.
2. **높은 보안성**: 순수 정적 파일만 제공되므로, 서버 측 취약점이 원천적으로 차단됩니다.
3. **깔끔한 문서 형태**: 개발자에게 친숙한 'Docs(문서)' 형태의 레이아웃을 제공하여, 본질적인 내용(글)에 집중할 수 있게 해줍니다.
